# PAXVEIL: руководство пользователя

PAXVEIL проверяет Python-зависимости, сохраняет отчёты и сравнивает варианты обновления. Для работы в Telegram откройте [@PAXVEIL_Bot](https://t.me/PAXVEIL_Bot). Отдельная регистрация в браузере не нужна.

Бот работает на компьютере владельца без платного хостинга. Он отвечает, пока включены компьютер, сеть и приложение. При выключении компьютера проверки и уведомления приостанавливаются.

## Первая проверка

1. Отправьте `/start`, затем `/example`.
2. Нажмите «Проверить пример». Бот сохранит проект с `requests==2.31.0` и выполнит обычную проверку по текущим источникам.
3. Откройте результат и сохраните JSON-отчёт. Пакет из примера не устанавливается.
4. Через `/projects` вернитесь к сохранённому проекту.

Для своего проекта отправьте файл с точным именем `requirements.txt`, `poetry.lock` или `uv.lock`. Подпись к файлу можно использовать как имя проекта. Размер ограничен 1 МиБ, состав: 300 зависимостей. Не загружайте пароли, токены и другие секреты.

Перед загрузкой выберите версию Python и систему через `/environment`. Этот выбор применяется к новым проектам. Уже сохранённый проект продолжает проверяться в своём окружении.

Если анализ выполняется долго, результат остаётся в очереди. Его можно открыть позже через список проектов. Повторная отправка одного действия не должна создавать вторую активную проверку того же проекта.

## Как читать результат

Находка означает, что проверенная версия связана с известной записью источника. Это не доказывает, что уязвимость достижима в вашем приложении.

CVSS описывает серьёзность, EPSS содержит датированную оценку вероятности эксплуатации, CISA KEV отмечает известную эксплуатацию. Приоритет помогает выбрать порядок разбора. Отсутствующий показатель остаётся неизвестным. Ошибки источников и неполный состав зависимостей видны в отчёте.

Результат без известных находок относится только к проверенным версиям и доступным источникам на момент проверки.

## Обновления, CVE и мониторинг

`/fixlab` предлагает выбрать проект и подход к обновлению: точечный, в пределах основной версии или полный. Предложенные релизы проверяются в PyPI, зависимости разрешаются по метаданным через uv, затем версии проверяются в OSV. FixLab не запускает тесты вашего приложения. Проверьте совместимость перед изменением рабочего окружения.

`/fire CVE-2024-35195` ищет CVE в сохранённом составе ваших проектов. Результат различает найденное совпадение, возможное совпадение, отсутствие совпадения и недостаток данных.

Через `/watch` включается повторная проверка проекта. В `/settings` задаются категории уведомлений, минимальный приоритет, часовой пояс, тихие часы и дайджест. Например:

```text
/timezone Europe/Moscow
/quiet 22:00 08:00
/priority 60
/digest on
```

Проверки и доставка выполняются фоновым процессом. Перезапуск бота сохраняет проекты и настройки. При недоступной сети доставка может задержаться. После сбоя между подтверждением Telegram и сохранением результата возможно повторное уведомление.

## Свои данные и ограничения

`/privacy` объясняет, какие данные сохраняются и куда отправляются названия пакетов и версии. `/export` выгружает ваши проекты, отчёты и настройки. `/delete_account` удаляет аккаунт и все его проекты после подтверждения. Для связанного веб-аккаунта это один общий аккаунт. Удаление проекта также убирает его историю и мониторинг.

Удаление относится к рабочей базе. Более старые записи могут оставаться в закрытых резервных копиях до ротации, обычно семь дней. Сообщения и отправленные файлы остаются в Telegram.

По умолчанию аккаунту доступны 10 проектов, 3 активные задачи и 10 новых анализов за предыдущий час. Лимит сохранённых данных составляет 64 МиБ. Старые отчёты и служебная история очищаются; последний пригодный полный отчёт для сравнения Watch сохраняется. При достижении лимита бот сообщает, что нужно сделать. [Подробные правила](PUBLIC_RESOURCES.md).

## Веб-приложение на этом компьютере

Откройте [http://localhost:3000](http://localhost:3000) на компьютере, где запущен PAXVEIL. Создайте аккаунт, выберите «Новый проект» и загрузите файл либо нажмите «Взять пример». Укажите окружение и запустите проверку.

Вкладки проекта: «Отчёт», «Зависимости», «Обновления», «История». В отчёте есть фильтры, из истории можно открыть отдельную проверку. FixLab продолжает работать при уходе со страницы; к заданию можно вернуться. Светлая и тёмная темы доступны на настольном и мобильном экране.

Если развёрнут доступный HTTPS-веб-интерфейс, в настройках можно получить одноразовый код и отправить боту `/link КОД`. Бот и браузер покажут одни проекты. В текущем локальном варианте бот скрывает недоступные ссылки на браузер и предоставляет отчёты прямо в Telegram. Адрес localhost с телефона ведёт на сам телефон.

## Запуск и обслуживание

На текущем компьютере окружение находится в `work/runtime`, рядом с `outputs`. Из каталога `outputs/paxveil` в PowerShell 7:

```powershell
.\scripts\stop.ps1 -RuntimeDirectory '..\..\work\runtime'
.\scripts\start.ps1 -Telegram -RuntimeDirectory '..\..\work\runtime'
```

Токен BotFather хранится только в поле `TELEGRAM_BOT_TOKEN` локального файла `.env`. Один токен обслуживается одним процессом polling. Включение автозапуска при входе в Windows, контроль процессов, ежедневные резервные копии и обновление описаны в [DEPLOYMENT.md](DEPLOYMENT.md). Полная нативная установка на чистом компьютере ещё не проверена; контейнеры проверены в GitHub Actions.
