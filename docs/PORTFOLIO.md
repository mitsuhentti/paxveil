# PAXVEIL: кейс для портфолио

PAXVEIL проверяет Python-зависимости, сохраняет отчёты и помогает сравнить варианты обновления. Веб-приложение и Telegram-бот используют один API с разграничением доступа по владельцу проекта. Мониторинг повторяет проверки и сообщает об изменениях.

## Задача

Одна уязвимость может иметь разные идентификаторы, источники иногда недоступны, а обновление пакета меняет зависимости. PAXVEIL сохраняет состав проекта, объединяет связанные записи, объясняет приоритет и показывает неполные данные.

FixLab разрешает зависимости по метаданным через uv и проверяет предложенные версии в OSV. Раздел «Проверка CVE» сопоставляет CVE с сохранёнными проектами.

## Данные и фоновые задания

| Задача | Решение |
|---|---|
| Хранение | PostgreSQL: пользователи, проекты, проверки, пакеты, версии, зависимости, уязвимости и находки; внешние ключи, индексы и уникальность |
| История | Неизменяемые JSON-отчёты, хеши и время получения публичных снимков, история статусов находок |
| Повторные проверки | Watch сравнивает результаты с предыдущей проверкой, учитывая полноту данных источников |
| Качество данных | ETL проверяет потерянные связи, дубликаты, диапазон приоритета и наличие отчёта у завершённой проверки |
| Аналитика | SQL-представления `scan_risk_metrics` и `notification_delivery_metrics`, команда чтения метрик |
| Надёжность | Очередь PostgreSQL с `SKIP LOCKED`, сроком владения заданием, уникальным токеном обработки и повторными попытками |
| Источники | OSV, PyPI, deps.dev, FIRST EPSS и CISA KEV; ошибки и неизвестные значения сохраняются в отчёте |

Для локального сценария достаточно PostgreSQL и отдельного планировщика, без Redis, Celery, Airflow и dbt. ETL-команды доступны внешнему планировщику.

## Серверная часть

FastAPI принимает пользовательские запросы, сканирование и FixLab выполняются в фоне. Пароли защищены PBKDF2, сессионные токены хранятся в виде хешей. API проверяет владельца каждого объекта. Привязка Telegram использует одноразовый код с ограниченным сроком действия.

Очередь уведомлений объединяет повторные события, учитывает категории, приоритет, тихие часы и дайджест, повторяет отправки и ведёт журнал. Загрузки ограничены форматом, размером и количеством зависимостей; файлы не исполняются. Запросы разрешены только к заданным HTTPS-адресам. Прокси FixLab пропускает обращения к официальным адресам PyPI.

Неполный ответ OSV виден в отчёте. CVSS, EPSS и CISA KEV отдельно описывают серьёзность, вероятность и подтверждённую эксплуатацию.

Стек: Python 3.11, FastAPI, Pydantic, SQLAlchemy, Alembic, PostgreSQL, httpx, uv, aiogram; Next.js, React и TypeScript. Есть lock-файлы и сценарии PowerShell 7. Docker Compose и GitHub Actions подготовлены, но контейнерный запуск и внешний CI ещё не выполнены: [результаты проверок](TEST_RESULTS.md).

## Интерфейс

Новый знак представляет собой геометрическую букву P. Светлая тема использует тёплый белый фон и синий акцент, тёмная сохраняет структуру. Навигация, таблицы и формы адаптируются к мобильному экрану. Рекламные подписи убраны.

Вкладки проекта: «Отчёт», «Зависимости», «Обновления», «История». Мониторинг и проверка CVE вынесены в разделы. Решения по оформлению: [DESIGN_REVIEW.md](DESIGN_REVIEW.md).

## Результаты проверок

Сканирование пяти публичных зависимостей с закреплёнными версиями выявило **12 уникальных находок**. FixLab Balanced и Maximum Coverage разрешили пять пакетов; повторные запросы OSV для предложенных версий не выявили известных уязвимостей. Minimal Change сообщил о недостатке данных для подходящего обновления. Проверка CVE подтвердила `CVE-2024-35195` для `requests==2.31.0`.

Проверка backend: **122 теста пройдены, 2 проверки публичных источников пропущены**. Через работающий API проверены загрузка, отчёты, история, настройки и экран шириной 390 пикселей. Результаты относятся к зафиксированным версиям и датам; совместимость приложения после обновления требует его собственных тестов.

Токен [@PAXVEIL_Bot](https://t.me/PAXVEIL_Bot) и polling проверены 11 октября 2026 года; владелец подтвердил меню `/start`. Загрузка файла, привязка, отчёт и доставка Watch ещё требуют проверки в Telegram. Автоматические тесты обработчиков используют подготовленные данные и транспорт.

## Как показать проект

После [локального запуска](DEPLOYMENT.md):

1. Создать аккаунт, выбрать файл `examples/browser/requirements.txt` и нажать «Создать проект и проверить».
2. Открыть «Отчёт», показать источники, находки и ограничения.
3. Во вкладке «Зависимости» открыть граф, изменить статус находки и показать «Историю».
4. Открыть «Обновления», запустить FixLab, сравнить версии и повторную проверку OSV. Указать необходимость проверки совместимости.
5. В разделе «Проверка CVE» ввести `CVE-2024-35195`, открыть совпадение и ссылку на источник.
6. Включить мониторинг, сохранить тихие часы, затем отключить его.
7. В настройках нажать «Получить код» и связать аккаунт с Telegram. Выполнить оставшиеся проверки файла и отчёта в боте.
8. Перезапустить приложение и сверить данные с [результатом проверки перезапуска](RUNTIME_VALIDATION.json).

Примеры зависимостей не устанавливаются. Подготовленные записи об уязвимостях используются только в тестах. Из публичной демонстрации нужно исключить `.env`, рабочее окружение, идентификаторы пользователей и приватные файлы. Скриншоты используют тестовые аккаунты и публичные пакеты.

## Что ещё проверить

Нужно проверить оставшиеся сценарии Telegram, Compose и восстановление резервной копии. Для публичного сервиса потребуются лимиты аккаунтов, сроки хранения данных, общие ограничения запросов, наблюдаемость и проверка нескольких worker с PostgreSQL.

Существующее окружение подготовлено повторно дважды с сохранением кластера и токена. После обычной остановки PostgreSQL вне изоляции Windows и перезапуска хеш QA-проекта, одной проверки, трёх статусов и подписки сохранился. Также проверены принудительная остановка собственного кластера и восстановление WAL. Установка с чистого окружения ещё не проверена.

[Операционные проверки](OPERATIONS_VALIDATION.md) описывают эти результаты. Текущее состояние и ограничения приведены в [PROJECT_STATUS.md](../PROJECT_STATUS.md).
